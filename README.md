# Mari Dias na Octoberfest YCSA 26

Aplicação estática para a “Lista da Banda” da Octoberfest YCSA em 23/10/2026.

Stack: Next.js + TypeScript + GitHub Pages + Google Sheets privado + Google Apps Script + Google Identity Services.

CPF é opcional e, quando informado, precisa ser válido. Nome e CPF nunca são devolvidos pela API pública.

## Comandos

- `npm ci`
- `npm run lint`
- `npm run typecheck`
- `npm run build`

Veja `docs/architecture.md` e `docs/setup.md`.
